# Reviews

Периодические ревью планирования, а не evidence о таргете. Ничто здесь не является runtime-, static- или synthetic-evidence и не может цитироваться как acceptance для roadmap item.

Ревью смотрит на роадмап как на инженерный артефакт: соответствие целям, критический путь, валидность графа зависимостей, бюджет дефицитных ресурсов, калибровку оценок, отсутствующие активности и сопровождаемость документа. Выводы ревью попадают в реальность только через обычные roadmap items и PR.
